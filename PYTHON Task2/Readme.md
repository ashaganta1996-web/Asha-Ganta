OOP Concepts:
1. Classes and Objects:
A class is a blueprint for creating objects. An object is an instance of a class.
2. Constructor:
A constructor is a special method called "__init__()" that initializes object attributes.
3. Encapsulation:
Encapsulation protects data by controlling access to class attributes and methods.
4. Inheritance:
Inheritance allows one class to acquire the properties and methods of another class.
5. Polymorphism:
Polymorphism allows the same method name to perform different actions depending on the object.
6. Abstraction:
Abstraction hides implementation details and shows only essential functionality using abstract classes and methods.
Four Pillars of OOP:
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
