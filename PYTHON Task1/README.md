Python Beginner Assignment

Project Description

This project is created to learn Python programming from the basics and develop simple working programs.

Objective

To understand Python fundamentals and independently create beginner-level Python programs.

- Visual Studio Code
- Git

- Comments

- For and While Loops

Exercises Completed

1. Age calculator
2.Number guessing game
3.Student score calculator
4.Create, add & update dictionary
5.Student score details
6.Loop through list
7.Store location in tuple
8.Methods of List, Set & Dictionary and Array operations

How to Run the Programs

1. Install Python 3.
2. Open the project folder in Visual Studio Code.
3. Open the required Python file.
4. Open the VS Code terminal.
5. Run the program using:

"python "Exercise 8.py""

Replace the filename with the program you want to execute.

Program Explanations

1. Student score Calculator

This program accepts a student score and uses if, elif and else statements to display the appropriate grade.

2. Student score details & calsulator

This program uses a Python set to remove duplicate numbers and counts the total unique values using len() and statement creates a function object in memory using def().
